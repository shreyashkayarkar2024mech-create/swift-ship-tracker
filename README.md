# Swift Ship Tracker

A Salesforce-based parcel management solution designed to simplify parcel booking, shipment tracking, and delivery operations using Salesforce automation and conversational AI.

## Project Overview

Customers often face difficulties booking parcels, tracking shipments, and obtaining delivery updates across multiple platforms.

Swift Ship Tracker aims to provide a centralized solution using Salesforce CRM, Flow Builder, Agentforce, and Prompt Builder.

## Objectives

* Manage customer, parcel, shipment, and delivery information.
* Support parcel booking and shipment tracking.
* Maintain shipment status and delivery history.
* Automate appropriate shipment-related operations.
* Provide AI-assisted shipment enquiries.
* Implement role-based access controls.
* Generate reports and dashboards for operational monitoring.

## Intended Users

* **Customer:** Books parcels and retrieves shipment information.
* **Delivery Agent:** Manages assigned shipments and records delivery updates.
* **Administrator:** Manages configuration, permissions, and operational reporting.

## Proposed Technology Stack

* Salesforce CRM and Lightning Experience
* Salesforce custom objects and relationships
* Salesforce Flow Builder
* Apex, where required
* Salesforce Agentforce
* Salesforce Prompt Builder
* Salesforce reports and dashboards
* GitHub for project documentation and version control
